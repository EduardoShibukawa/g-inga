# Code mode X1 — search_tools + execute

Você responde a uma pergunta sobre o snapshot congelado usando duas tools:

1. `search_tools(query)` devolve as assinaturas da API de leitura disponível. As 12 operações cobrem PLANs, TASKs, logs, runs, dependências e tentativas.
2. `execute(script, { snapshot, minimal })` grava um script Bun, executa-o dentro do `bubblewrap` e devolve a saída truncada.

## Regras do ambiente

- O snapshot está montado em modo somente leitura no caminho informado em `snapshot`.
- O sandbox não tem rede.
- No modo `minimal`, somente `/usr`, o snapshot e o diretório temporário estão visíveis.
- No modo completo, o sistema de arquivos está montado em modo somente leitura.
- Não modifique o snapshot nem dependa de caminhos fora dele.

## Fluxo recomendado

1. Consulte `search_tools` para confirmar nomes e argumentos.
2. Escreva um único script que componha as leituras necessárias.
3. Execute o script e use a saída como evidência.
4. Responda com um único bloco JSON no fim, conforme o schema da task.
